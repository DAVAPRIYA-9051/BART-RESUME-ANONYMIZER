BIAS REMOVAL AND ANONYMIZATION API LAYER FOR RESUMES

BRIEF DISCRIPTION:
    A high performance, privacy first bias anonymization API layer. Unlike legacy pattern matching tool, BART uses "Context-Aware
Generative AI" to intelligently detect and anonymize PII from resumes without breaking the context 

FEATURES:
    > Smart PII Detection
    > High-Speed Execution
    > Layout-Preserving Processing
    > Enterprise-Grade Security

TECH STACK:
    > LANGUAGE: PYTHON 3.10
    > Document Handling: Reportlab
    > FRAMEWORK: FAST API, UVICORN, 
    > AI MODEL: GOOGLE GEMINI API (GOOGLE GENAI)
